# Appunti Algoritmi e Strutture Dati

Questa repository raccoglie il codice prodotto durante il corso di **Algoritmi e Strutture Dati**, con particolare focus sulle **implementazioni degli algoritmi** in Python cercando di spiegare nel modo più semplice possibile ogni riga di codice scritta.

## A chi è utile?

Questo materiale è pensato per gli studenti che dovranno affrontare l'esame di Algoritmi e Strutture Dati e vogliono un punto di partenza concreto per **comprendere come un algoritmo viene implementato**, senza dover scrivere tutto da zero.

## Struttura della Repository
### `Codici/`
Contiene il codice per le primitive usate nelle tracce o primitive specifiche
### `MaterialeTeorico/`
Contiene codice con algoritmi standard implementati a mano e commentati su ogni riga scritta
### `TracceSvolte/`
Contiene la traccia e il relativo codice usato per svolgerla
